# Feasibility and accuracy

Most "Today" claims hold, but several "Built" marks are overstated: the paid confirm and license verification are enforced by agent rules rather than by the tool, the UI cannot tell placeholder audio from paid audio, and the license check covers library sounds and providers but not individual voices or images. The biggest feasibility risk is the phone story: playback stops when the screen locks, and the phone checklist has never been run on a real phone. Several acceptance criteria and success measures depend on agent behavior or on events outside the tool, so they cannot be tested as written.

## Findings

| ID | Severity | Finding | Affects | Suggestion |
|---|---|---|---|---|
| FE1 | High | Neither the paid confirm nor license verification can tell a human from an agent. `--yes` and an unauthenticated localhost API both let an agent approve its own spending or verify a license. | R7, R26, Constraints (Cost, Rights), Success 3 | Mark R7 and R26 Partial. Say in the acceptance whether "human only" is a rule or is enforced, and add a testable criterion such as "a process with no human input cannot start a billed call". |
| FE2 | High | Placeholder and paid audio look the same in the UI, and `vd render` accepts mock tones, so a final render can ship placeholder beeps without a warning. | R13, R28, Success 3 | Mark R13 Partial. Add to R28's acceptance: "render names every item whose audio came from the free provider". |
| FE3 | High | The commute story needs listening with the screen locked. Playback stops on lock by design, and Web Audio scheduling in a background mobile tab is not reliable on iOS Safari or Android Chrome. On iPhone, the silent switch may also mute Web Audio. | R10, Before/after, Assumption (phone) | Write R10 as "with the screen on", or add a separate requirement for background listening, rated as costly. Make the real-phone checklist part of R10's acceptance. |
| FE4 | Medium | The tool shows cost as characters and requests. ElevenLabs bills credits, which vary by model, and music by length, which the estimate shows as 0. The usage API is per account, not per drama. | R7, R9, Job 3 | State the cost unit in R7 ("in the provider's billing unit, or marked as estimated"). Scope R9 to an estimate from local records. |
| FE5 | Medium | Rights checks stop at providers and library entries. Shared voices from a voice library may carry their own terms, and images have no record. | R27, R29, Job 8 | Reword R27 to "every library sound and provider" (Built). Add a requirement for voice and image rights, or move images explicitly into the non-goals. |
| FE6 | Medium | "Everything runs on the user's machine" is false: TTS sends the script to ElevenLabs, coding agents send files to their vendor, and Tailscale needs an account and publishes the machine name in a certificate log. | R32, Constraints (Privacy) | Reword: "the tool hosts nothing; content leaves the machine only to the providers and agents the user chose". Make R32's acceptance something the tool can test, such as "no vd command reads or uploads the user directory beyond config.yaml". |
| FE7 | Medium | A fix in under a minute is feasible with edit and regenerate, which takes seconds per line plus the confirm step.
